# СТАРТОВЫЙ ПРОМТ (вставляется в новый чат вместе с вложениями)

**Вложи в чат:** архив `kap-kit.zip` (распакуй его там, где у модели есть доступ к файлам и запуску Node.js), файлы КСП и базу целей обучения / учебную программу. Для Claude Code можно положить всё в рабочую папку проекта.

---

Ты создаёшь цифровой образовательный материал (ЦОМ) по приложенным КСП и базе целей обучения РК.

**Правила — в файле `MASTER_PROMPT.md` из архива. Выполняй их полностью**, особенно разделы 1–2 (источники и пререквизиты), 7–14 (генераторы, рандомизация, оценивание), 25 (живое педагогическое начало), 26 (коррекционный цикл).

**Код ядра писать не нужно.** Готовое ядро находится в `kap-engine.js` (из архива). Твоя работа — написать один файл `pack.js` с уроками и генераторами по описанию в `PACK_FORMAT.md` (образец — `example-pack.js`).

## Порядок работы

1. Прочитай все КСП и базу целей. Для каждого урока определи внутри себя: текущие цели, подтверждённые пререквизиты, безопасные операции, ещё не изученное, запрещённые скрытые пререквизиты. Если базы нет, действуй консервативно (раздел 1.5 промта).
2. Для каждого КСП напиши урок в `pack.js`: цели, критерии и дескрипторы, виды оценивания, время и баллы **строго из КСП** (веса — только если КСП их задаёт), поднавыки с карточками правил, этапы по единому каркасу. Очные этапы КСП (дискуссия, эксперимент, защита) оставь очными: карточка с инструкцией и полем фиксации, не тест.
3. Для заданий напиши параметрические генераторы с реальной вариативностью (структурной, не только числа), типичными ошибками в дистракторах и подсказками. Добавь задания на понимание, перенос, поиск ошибки; в итоговой проверке не меньше четверти заданий уровня «понимание» и выше. Задай `programMap.forbiddenTerms` с признаками ещё не изученного материала.
4. Запусти `node kap-engine.js check pack.js`. **Исправляй ошибки, пока их не останется**, предупреждения разбери и устрани или обоснуй.
5. Запусти `node kap-engine.js all pack.js out`: проверка, сборка двух HTML и испытание в браузере. Если браузер недоступен, прямо напиши, что браузерная проверка не выполнена.
6. Выдай файлы `out/student_material.html` и `out/teacher_console.html` и краткий отчёт по разделу 22 промта: уроки, цели, пререквизиты, виды оценивания, что цифровизировано и что осталось очным, генераторы и реальные результаты тестов, допущения, что не проверено.

## Что нельзя

- Выдумывать задания официальных ПО, СОР, СОЧ, если они не приложены.
- Выходить за программу в основном курсе (расширение допустимо только в этапе Клуб).
- Утверждать, что тесты пройдены, если ты их не запускал.
- Переписывать или править ядро. Если нашёл дефект ядра, опиши его в отчёте.
- Задавать вопросы, ответ на которые есть в КСП и базе целей.
