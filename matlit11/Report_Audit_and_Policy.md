## 5. Политика клонирования

### 5.1. Что считать новым заданием
Клон должен отличаться от пула хотя бы одним из следующих режимов. Смена только чисел или только сюжета новизны не даёт.

| Режим | Что меняется | Пример (слот 7) |
|---|---|---|
| **D** прямая | то же, но с новыми данными | 10 участников → число партий |
| **I** обратная | результат дан, ищется исходное | сыграно 28 партий → сколько участников |
| **T** смена представления | текст ↔ таблица ↔ график ↔ рисунок | |
| **K** смена структуры | добавить/убрать условие, второй шаг, другой вопрос | |
| **C** контекст | сюжет | турнир → рукопожатия |
| **N** числа | допустимо только вместе с D/I/T/K | |

В варианте должно быть 3–5 обратных или «изменённых по условию» заданий из 10. В соседних слотах не более 2 обратных подряд.

### 5.4. Баланс варианта (проверяется автоматически)
- **Сумма сложностей** 23 (допуск 21–25), отклонение по слоту не более ±1 от цели. Сумма шагов 25–29, вес содержания 15–17.
- **Профиль:** формальные слоты (1, 3, 7, 10) 8–12, нестандартные (5, 8, 9) 8–10, данные (2, 4, 6) 3–5. Тогда не будет перекоса вида «18461 vs 16498».

- **Дистракторы:** каждый получен из конкретной типовой ошибки и подписан в служебной карте. Он не отсекается формальным признаком (делимость, знак, единицы). Все варианты одного вида (одни дроби или одни десятичные) и допустимы по смыслу (оценка ≤ 5, вероятность ≤ 1, число людей целое).

### 5.5. Контроль качества каждого клона
1. Ответ считается независимым кодом по параметрам, а не берётся у генератора.
2. Ровно один вариант совпадает с ответом, дистракторы дают заданные числа, все различны.
3. Единицы совпадают в условии, на рисунке и в ответах.
4. Условие однозначно (порядок значений, «включая первый день»). Термины соответствуют виду данных (таблица, диаграмма, график).
5. Нет латиницы в русских словах и мягких переносов. Контекст реалистичен.
6. Слова, ничего не меняющие, убраны («впервые» при единственном вхождении, «наибольшее количество» без смысла).
7. Данные на рисунке считываются однозначно: значения на линиях сетки, начало кривой внутри оси. Рисунок строится из данных и проверяется по данным.
8. Нет совпадения с пулом по условию, ответу и промежуточным числам. Так исключается повтор вроде №1655.
