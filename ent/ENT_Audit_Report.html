6. Политика клонирования (кратко)

  1. Паспорт слота: номер, тема, форма (прямая / обратная / по рисунку / кейс / соответствие / множественный выбор), целевой уровень, тип ответа, число верных вариантов. 40+10 слотов описаны в политике.
  2. Операторы вариации кроме смены чисел: прямая ↔ обратная, другой объект/формула, смена представления (формула ↔ график ↔ таблица), добавление ловушки (ОДЗ, отбор корня, знак), цепочка двух навыков, смена контекста кейса, лишние/недостающие данные.

  4. Генерация дистракторов по модели типичных ошибок (знак, потеря корня, не та формула), без дублей по значению.
  5. Контрольные ворота: независимый пересчёт ответа кодом, ровно k верных вариантов, ключ полный (все 40 ответов), баланс позиций, профиль сложности по блокам, проверка на повтор ядра задачи в соседних вариантах. Найденные в этих трёх вариантах дефекты — это регрессионные тесты.
